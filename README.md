# MemoCare

Early-detection and monitoring platform for memory care (React frontend + Node/Express/Prisma backend + built-in local PostgreSQL).

**Start here:** [docs/SETUP-GUIDE.pdf](docs/SETUP-GUIDE.pdf) (same content: [docs/SETUP-GUIDE.md](docs/SETUP-GUIDE.md))

Quick start (after installing Node.js 20+):

- Windows: double-click `START-MEMOCARE.bat`
- Mac/Linux: `./START-MEMOCARE.sh`
- Then open http://localhost:4000
